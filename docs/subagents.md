# V6：主 Agent 与子 Agent 协作

确认日期：2026-10-29。一个终端对应一个主会话；多个终端独立运行。保留 /new、/resume，
不新增一个终端切换并行主会话的界面。

## 已确认的行为

- 主 Agent 提供任务与必要背景，子 Agent 使用独立上下文，不默认复制全部父历史。
- 同一主会话可继续追问已有子 Agent；保存独立 JSONL，重启标记中断，不自动重发。
- 子 Agent 沿用启动时的读取范围，不获得新的批准权限，不再创建子 Agent。
  当前修改文件和通用命令均需逐次批准，因此子 Agent 将此类需求交给主 Agent。
- 默认最多并发 2 个，每个主轮次最多新建 4 个，可在 [subagents] 配置。
- 主会话与所有子 Agent 共享 agent.max_session_tokens；每个子轮次仍受请求和工具次数限制。
- 终端只显示启动、完成、失败等简短状态，主 Agent 汇总正文。
  可单独停止一个子 Agent；Ctrl+C 停止本主任务及其所有运行中的子任务，其他终端不受影响。

## 额度口径

请求前预留估算输入加输出上限，检查与预留在同一锁内，防止两个请求重复使用剩余额度。
实际结算使用 API 报告值，失败消费也计入；用量未知阻止本组新请求。
已经发出的其他请求允许结束并记账，取消一个任务不会主动取消其他任务。
估算与模型分词可能不同，这不是人民币硬限额，也不能保证单次请求绝不超出总 token 上限。
