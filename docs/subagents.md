# V6：主 Agent 与子 Agent 协作

确认日期：2026-10-29。一个终端对应一个主会话；多个终端独立运行。保留 /new、/resume，
不新增一个终端切换并行主会话的界面。

## 已确认的行为

- 主 Agent 提供任务与必要背景，子 Agent 使用独立上下文，不默认复制全部父历史。
- 同一主会话可继续追问已有子 Agent；保存独立 JSONL，重启将未完成任务标为中断，已提交结果按日志恢复，不自动重发。
- 子 Agent 沿用启动时的读取范围，不获得新的批准权限，不再创建子 Agent。
  当前修改文件和通用命令均需逐次批准，因此子 Agent 将此类需求交给主 Agent。
- 默认最多并发 2 个，每个主轮次最多新建 4 个，可在 [subagents] 配置。
- 主会话与所有子 Agent 共享 agent.max_session_tokens；每个子轮次仍受请求和工具次数限制。
- 终端只显示启动、完成、失败等简短状态，主 Agent 汇总正文。
  可单独停止一个子 Agent；Ctrl+C 停止本主任务及其所有运行中的子任务，其他终端不受影响。

## 如何使用

直接向主 Agent 描述可拆分的任务，例如：

> 请派两个子 Agent 分别检查配置加载和会话恢复，各自给出文件依据，你汇总它们的结果。

模型可调用 spawn_agent、send_message、list_agents、wait_agents、interrupt_agent。
spawn_agent 立即返回 ID，主 Agent 可以继续请求或执行自己的工具。
send_message 用于已结束的子 Agent；运行中补充任务会明确拒绝。同轮追问前须先用 wait_agents 收集上次结果，避免后续运行替代未交付结果。
wait_agents 可等全部或指定 ID，最多一次等待 30 秒；结果正文有界，单独查询可得到更长正文。
没有读取本轮派发结果时，程序不接受主模型提前结束；提醒和重新请求仍计入本轮上限。
子回复以工具结果进入上下文，不作为系统指令或审批授权。

存储位置：sessions/_subagents/<主会话ID>/index.json 保存派发关系及结果索引，
同目录的 sessions/YYYY/MM/DD/<子AgentID>.jsonl 保存子会话。/sessions 仍只列出主会话。
索引用临时文件 fsync 后原子替换，子会话继续使用现有持锁 JSONL 恢复。
每次派发关联父 turn_id、request_id、tool_call_id 和实际 child_turn_id；
异常退出后，未完成子轮次记为 interrupted；若子 JSONL 已完整提交，则恢复 completed 与原回答。索引不能覆盖已保存的执行事实，全部场景都不自动重发。
索引缺失而子日志存在时明确报错，不能将子消费清零。备份必须保留完整 _subagents 目录。

子 Agent 继承主会话系统约束、固定工作目录与额外读取目录。配置范围改变后，
旧子 Agent 不自动获得新授权，需新建；主会话用户历史默认不复制。

自动化按业务分为：
- [委派闭环](../tests/features/test_subagents.py)：7 个场景，覆盖并行、追问、权限、来源和结果收集。
- [中断与恢复](../tests/features/test_subagent_recovery.py)：6 个场景，使用独立进程和真实本地 TCP。
  包括响应头/正文/已知用量后的 Ctrl+C、单独停止 A 而 B 继续、另一终端不受影响，
  以及请求中、子回答提交后两个强杀边界。
- [资源与失败边界](../tests/features/test_subagent_boundaries.py)：7 个场景，覆盖摘要/重试聚合、
  索引原子替换失败、缺失索引、结果大小、读取范围和会话切换隔离。

共 20 个业务场景，另有 V6.1 的 9 个基础用例。测试中的模型回复均由本地服务或 MockTransport
提供，文件、线程、锁、JSONL、索引、信号与进程强杀实际执行。网络取消以关闭本地等待和连接为界，
不能保证服务商停止远端计费；未知用量保持未知。文件读取等同步本地操作在阶段边界协作取消。

## 额度口径

请求前预留估算输入加输出上限，检查与预留在同一锁内，防止两个请求重复使用剩余额度。
实际结算使用 API 报告值，失败消费也计入；用量未知阻止本组新请求。
已经发出的其他请求允许结束并记账，取消一个任务不会主动取消其他任务。
估算与模型分词可能不同，这不是人民币硬限额，也不能保证单次请求绝不超出总 token 上限。
