# C 系列：扩展 Agent 的观察、动作与学习能力

规划日期：2026-11-01。状态：已开始实施 C01～C10 及按需 C00；各项以独立勾选和验收记录为准，C11～C14 不在本轮主动实施范围。

本文件同时保留完整规划与实施状态；未勾选项不表示已有功能。总入口见 [练手 TODO](agent-practice-todo.md)，模块边界见 [能力模块设计](capability-module-design.md)。已实现系统仍以 [当前架构](architecture.md) 为准。

## 已确认的范围

- 14 类方向全部纳入，分为应用能力与研究实验；每类都安排真实最小闭环。
- 同一 Python 工程按能力分包，内核依赖窄接口，SDK 放在适配器内。资源由所属模块管理，扩展可选安装。
- 自动化工程验收与真实模型/设备验收分开；没有设备、预算或合适模型时保留未完成，不以 Mock 通过代替。
- C 系列按依赖穿插 B 系列，不要求先完成全部 B。B 的细项状态只在 [B 系列路线](agent-book-practice-plan.md) 维护，本文不复制其勾选。
- 每个小任务是一次可独立理解的改动与提交；先做一种后端、一个平台、一组固定任务。网页聊天界面、商业账号体系、大规模训练平台不在本轮目标内。

编号用于稳定引用，不代表必须按 C01 到 C14 串行。下文的后端与数量是实施起点；开工时核对本机环境与 API，调整须记录原因。

## C01 联网搜索与网页阅读

前置：现有工具/权限/日志，C00.1。责任包建议 `adam/web/`。搜索与抓取是两个端口，不依赖浏览器包；搜索服务商在开工时选一个。

- [x] C01.1 网页抓取：URL → 有界正文、标题、最终 URL、抓取时间与内容摘要；在真实本地 HTTP 服务验证重定向、超时、错误类型和大小限制。网络策略检查每次连接/重定向；本地测试放行不成为生产默认。
- [x] C01.2 搜索后端：关键词 → 有界候选列表（标题、URL、摘要）；接入一个真实可用服务，凭据仅由适配器读取。无结果、限流和缺少配置给出可区分结果，摘要不冒充已读正文。
- [x] C01.3 工具闭环与引用：搜索 → 选择网页 → 阅读 → 回答；来源 ID 映射抓取版本与片段。自动化用模拟模型和真实测试网站；网页中的指令只当资料，不能扩大权限。
- [ ] C01.4 真实对照：固定 5 题（时效、来源冲突、无答案、重定向、无需搜索），记录引用是否支持结论、成本和耗时；工程与真实搜索/模型状态分别记录。

练习价值：网络失败、来源建模、检索证据。先不做爬虫集群、搜索引擎或登录态网页；动态交互交给 C02。

## C02 有状态浏览器操作

前置：C00.1；截图作为模型输入时另需 C00.2/3、C04。C01 可复用但不是硬前置。责任包 `adam/browser/`，首版一个 Chromium 后端。Playwright 有 Python 库及同步/异步接口，适合隔离在适配器中；这是一项项目选型建议。[官方文档](https://playwright.dev/python/docs/library)

- [x] C02.1 观察：打开测试页面，返回页面/标签身份、URL、文本及可操作元素引用；观察包含版本，控件失效要求重新观察。自动化使用真实浏览器和本地网站。
- [x] C02.2 动作：按引用点击、输入、选择和滚动；执行走原权限/批准入口。检查页面身份与当前元素，验证表单真实结果；禁止让模型直接传任意宿主执行代码。
- [x] C02.3 生命周期：会话拥有浏览器上下文，管理标签页、弹窗、下载引用；关闭/取消回收资源，崩溃不宣称动作未发生、不自动重提表单。
- [ ] C02.4 完整验收：模型在固定网站查询记录并提交一条测试表单，读取页面结果作为成功证据；覆盖过期引用、页面跳转、重复提交与取消。真实模型能否选对控件单列。

边界：只需一套测试网站，不做网页聊天产品；浏览器登录身份与 cookies 不写入模型上下文或普通日志；观察中的随机资源 ID 只用于引用校验。

## C03 桌面 Computer Use

前置：C00.1～C00.3、C04.1/2；会占用交互桌面，开工选择独立测试窗口/桌面。责任包 `adam/desktop/`，首版 Windows。UI Automation 提供控件信息及程序化操作接口；控件不可用时才进入截图定位路径。[Microsoft 文档](https://learn.microsoft.com/en-us/windows/win32/winauto/entry-uiauto-win32)

- [ ] C03.1 窗口观察：目标窗口身份、控件树、截图引用、尺寸/DPI/观察版本；验证窗口切换与缩放后的坐标映射，文字与像素观察都保留来源。
- [ ] C03.2 有界动作：优先控件操作，补点击、输入、快捷键；每次校验窗口与观察是否仍有效，动作后重新观察。权限/批准仍由原执行入口决定，屏幕上的文字不授予新权限。
- [ ] C03.3 资源与停止：一个桌面输入租约避免主/子任务抢键鼠；丢焦点、锁屏、取消立即停止后续动作；恢复时先观察，不盲目继续点击。
- [ ] C03.4 实机验收：在测试应用读取字段、填写并保存到临时目录，独立读取文件验证内容；覆盖过期截图、遮挡和中途取消。自动化只覆盖适配器/状态逻辑，真实桌面闭环另留证据。

边界：首版不操纵用户日常正在编辑的窗口；不把坐标脚本执行成功等同于模型理解屏幕成功。

## C04 图片理解与 OCR

前置：C00.2/3；扫描 PDF 分支另依赖 B17.1/2 的来源和页码，不重做文本提取。责任包 `adam/vision/`，已有 `adam/documents/` 通过解析端口消费 OCR 结果。

- [ ] C04.1 图片输入：真实图片 → 版本化媒体引用、尺寸/方向/格式；做解码大小限制与清晰的损坏提示，模型不支持图像时明确能力不足。
- [ ] C04.2 视觉问答：一个真实视觉模型适配器，输入图像和问题，输出回答及所引用图像；成本、超时、取消进入统一记录。验收包含文字标签与非文字布局问题，OCR 成功不代替视觉推理。
- [ ] C04.3 OCR 与扫描页：一个 OCR 后端返回文本、页/区域坐标及其原生置信信息（没有则未知）；接入 B17 的混合 PDF，标记识别文本来源及错误可能，保留原页证据。
- [ ] C04.4 对照验收：图片、清晰扫描、模糊扫描、旋转、文本/扫描混合 PDF；分别报告转写错误、问题正确性和定位准确性，模拟模型测试不代替真实 OCR/视觉测试。

边界：先完成固定样本与一个后端，不建设通用文档版面平台。

## C05 语音交互

前置：C00.2/4；C05.1～3 通过文本进入现有会话，无需等待端到端音频模型。C05.4 依赖 B27 的安全点输入。责任包 `adam/audio/`。

- [ ] C05.1 录音与转写：按键开始/结束 → 有界录音 → 一个 ASR 后端 → 可确认/编辑的文本；保存输入来源，验证静音、设备缺失、超长和取消，不把录音失败当空用户请求。
- [ ] C05.2 接入对话：确认后的转写只提交一次，复用现有 Conversation；转写文本遵守和键盘输入相同的权限，不能凭“语音命令”绕过批准。重试不产生重复轮次。
- [ ] C05.3 合成与播放：回答文本 → 一个 TTS 后端 → 可播放音频；支持停止播放并释放设备。模型轮次成功与朗读失败分别记录，不能因播放失败重发模型请求。
- [ ] C05.4 打断与实机验收：先停止播报，再在 B27 安全点提交新输入；轮次/播放 ID 防止过时声音回放。真实麦克风完成 5 轮含一次打断，记录转写准确度、首音延迟和取消耗时。

边界：先按键讲话，不做一直监听、声纹登录、电话接入或仿声。端到端实时音频是后续替换适配器的实验，不是首个闭环前置。

## C06 视频与连续观察

前置：C04、C00.4。责任包 `adam/video/`，调用帧分析端口，不直接导入视觉模型 SDK。

- [ ] C06.1 有界视频解码：短视频 → 带时间戳的帧引用，限制时长、分辨率及采样数；损坏、可变帧率和取消可诊断，帧时间来自真实媒体时间轴。
- [ ] C06.2 时序分析：帧序列 → 事件片段及起止时间/证据帧；回答“先后发生了什么”，允许表示不确定。验证打乱帧与缺帧不会仍报告同一确定顺序。
- [ ] C06.3 连续观察实验：复用相同帧流契约读取摄像头或测试视频的实时播放，背压时丢弃过旧观察并记录；固定短片与实时源各跑一次，比较采样率、事件漏检、延时和成本。

边界：先观察并回答，不自动联动桌面动作；无摄像头可完成视频分支，但实时设备验收保持待办。

## C07 图片、音频等媒体生成

前置：C00.2/4。责任包 `adam/generation/`。C05 的朗读是语音交互，不能单独视为本方向全部完成。

- [ ] C07.1 生成作业契约：提示、参数、种子（后端支持时）、作业身份 → 状态与媒体引用；接入现有取消/额度，说明远端取消不一定撤销已产生费用，未知状态不自动重提。
- [ ] C07.2 真实双模态最小后端：先生成一张图片，再生成一段短音频/音效；二者使用独立适配器并保存真实可解码产物。凭据未配置明确失败，不能用空文件或占位图验收。
- [ ] C07.3 产物闭环：模型发起生成、查询结果并交付本地引用；覆盖写入失败、重复通知、作业超时和成本未知。质量由真实样本验收，验证产物格式不能代替质量判断。

边界：不做素材网站或编辑器；视频生成可作为同一作业契约的后续第三种适配器，不影响图片/音频小闭环。

## C08 图结构知识检索

前置：E2 来源/版本与检索；融合对照依赖 B09，发布复用 B12。责任包先扩展 `adam/documents/graph/`，首版本地邻接表或简单关系存储，不上图数据库集群。

- [ ] C08.1 证据图：从小语料提取实体/关系候选，每条边带原文定位、来源版本和提取方式；同名实体歧义保留，不靠名字自动合并。
- [ ] C08.2 有界多跳查询：限制节点、边和跳数，返回两跳路径及每条边的证据；图中无依据就返回缺失，防止模型把推断补成事实。
- [ ] C08.3 更新与融合：源变动使对应边失效；图候选与 B09 文本候选按来源合并，人工确认的知识沿用 B12，图的生成不自动发布长期知识。
- [ ] C08.4 对照：准备单点、两跳、同名歧义、无答案和过期资料问题，比较纯文本/图增强的正确率与证据完整性；至少展示一个图有益和一个无益案例。

最小例子：“模块 A 调用了哪项服务，该服务由谁维护？”答案须同时引用调用关系与维护者来源。

## C09 跨系统 Agent 协作

前置：已有子任务状态/取消；C00.2 用于媒体产物，C14.1 用于身份约束，网络部署需 C14.2。责任包 `adam/interop/`。A2A 规范定义任务、消息、产物及查询/取消等操作；实现时固定协议版本并写明支持子集。[官方规范](https://a2a-protocol.org/latest/specification/)

- [ ] C09.1 独立进程最小协议：Agent Card/能力发现、发送文本任务与结果，两个真实进程互通；公共端口不暴露 SDK 类型，远端 Agent 不取得本地 SessionStore 对象。
- [ ] C09.2 生命周期：远端任务 ID 与本地关联 ID 映射，查询、流式进度（选定子集支持时）、取消和终态；断连后查询原任务，不能盲目重新委派产生重复副作用。
- [ ] C09.3 接入主 Agent：通过现有工具/审批调度独立服务，返回证据与不确定状态；本地批准不隐式授予远端机器权限，远端费用有来源/上限且未知保持未知。
- [ ] C09.4 互操作验收：与一个固定版本的参考服务完成成功、失败、取消、重复提交、超时后查询；只支持的操作逐项列出，私有 JSON 互通不宣称完整兼容 A2A。

边界：先 localhost，之后才扩展网络身份；不做 Agent 市场、服务发现集群或无限多 Agent 团队。

## C10 移动端与机器人动作空间

前置：C00.1～3、C04；采用模拟器，实际设备是后续单独范围。`adam/mobile/` 与 `adam/robotics/` 分开，不共用“万能 execute”接口。

- [ ] C10.1 Android 观察：一个模拟器和测试应用，提供 UI 层级、截图引用、设备/页面版本；一个设备一个输入租约，断连/旋转要求重新观察。
