## T1 自动加载项目规则

目标：按工作目录与目标路径，自动使用根目录和子目录 AGENTS.md。
工作目录为本次规则根，不扫描目录树；只沿实际目标的祖先路径发现规则。
根规则仅适用项目范围，子规则仅适用其子树；同一范围冲突时更近的规则优先，当前用户要求和程序权限保持原边界。
每文件最多 16 KiB、合计 64 KiB、最多 16 份，内容不能静默截断。拒绝读取越界链接或被保护目录。
每轮重取根规则；新路径或文件变化导致的新规则必须先发给模型，再执行涉及的工具。
命令按 cwd 加载规则，不静态推断命令内部可能访问的所有路径。
规则来源、范围、版本及实际内容记入请求快照；重启查看旧请求不重新读取源文件。

- [x] T1.1：有界规则读取、作用域与版本契约；验证根/子/兄弟目录、更新删除、坏编码、大小与链接边界。
- [x] T1.2：接入主/子 Agent、上下文预算与工具前检查；验证新规则未展示时没有编辑或命令副作用。

## T3 Skill 发现与显式启用

目标：用户级和项目级 Skill 均可发现，项目级同名项优先；显示来源及被覆盖项。

## T4 规划模式与执行模式

目标：plan 模式仅允许调查与内部计划/会话记录；act 模式保持原有逐次审批。
只由用户命令 /mode plan|act 切换，模型工具和项目规则不能切换；子任务继承主任务限制。
模式是运行时设置，启动默认 act 并明确展示，现有确认机制保持；不将模式命令作为聊天请求。
工具由能力声明分类，未知扩展工具在 plan 模式中拒绝，不能仅凭名称推断安全性。

## T5 生命周期 Hooks

目标：用户可配置工具执行前与执行后两个事件，扩展检查不改主循环。
前置 Hook 返回允许/拒绝；后置 Hook 只审计已发生的事实，不能将已完成动作改成未执行。
本地检查器通过有界 JSON 输入输出在独立进程执行，配置由用户控制，默认关闭，不作为操作系统沙箱。
设置超时与输出上限；前置失败阻止工具，后置失败保留实际结果并报告，禁止 Hook 递归触发自身。
不向 Hook 提供模型认证配置。

- [x] T5.1：事件/结果契约、配置与独立进程检查器，验证合法响应、超时、坏 JSON 与非零退出。
- [x] T5.2：接入工具执行边界、审计记录及取消；验证拒绝零副作用、后置错误不掩盖结果。
- [x] T5.3：两个可运行示例和业务验收，覆盖模式、审批、日志失败与关闭时原有行为。

## T7 修改检查点与撤销

目标：专用编辑工具成功修改后，用户可撤销最近一次单文件修改。
写入前可靠保存原内容与来源，成功后固定修改后版本；失败或未知编辑不能伪装成可撤销成功记录。
/undo 展示逆向差异并请求批准；当前文件不再等于修改后版本时拒绝覆盖。
不撤销任意 shell 命令；不覆盖外部修改。保留原编辑和撤销记录，可检查重启状态。

## T8 大工具结果按需读取

目标：长工具文本保留为会话附件，模型先收到摘要与引用，再通过工具分段读取。
附件只接受有限 UTF-8 文本，内容与版本固定；超过总保存上限明确标记不完整，不声称完整保存。
附件按会话隔离，来源可追溯；实际读取内容计入现有上下文预算。
保存失败不能假装有可用附件，备份说明包含附件目录；不增加清理服务或向量索引。

## T9 调用录制与离线重放

目标：录制单轮模型响应、工具结果及必要配置，离线复现同一执行流程。
录制不保存认证头或 API 密钥；重放不调用真实模型、不重新执行文件修改、命令或子任务。
内部流程仍使用真实控制与预算逻辑，对比请求/工具次序和参数，报告首次差异位置。
初版只录制显式选定的单轮；重放写独立诊断数据，不修改原会话。

## T10 语法感知代码定位

目标：使用 Python AST 提取模块、类、函数、导入及定义位置，提供有依据的代码结构查询。
符号身份包含模块和作用域，区分同名对象；仅报告静态可确定的引用，动态情况明确未知。
扫描有数量/字节/时间限制，沿用路径权限；文件更新/删除后结果刷新，不执行目标代码。

## T11 子 Agent 提交修改提案

目标：只读子 Agent 返回结构化提案，主 Agent 统一展示差异、申请批准并应用。
提案必须关联子任务的实际读取、原文件版本和唯一替换内容；模型自报不能直接当执行证据。
主 Agent 应用复用编辑及 T7 检查点；子 Agent 仍不能直接改文件或申请更大权限。
两个提案基于同一旧版本时，应用第一个后第二个必须重新检查，不静默覆盖。
