## 5.1 的使用与边界

在 llm.toml 的 [llm] 中设置 stream=true（默认），不支持 SSE 的服务可显式设为 false。不自动发第二次请求尝试另一种模式。

正文增量只用于终端显示；reasoning_content 保留供服务商后续工具请求使用，不展示。工具片段按 index 拼接，必须有合法结束原因和 [DONE]，再经现有消息校验及工具参数校验。流式断开、截断或协议无效时不执行不完整工具，也不把部分回答写成成功历史。

收到可靠 usage 则照常计入消费；未收到时维持未知状态并阻止该会话继续花费。没有新增日志版本，也不逐片写 JSONL。

协议依据：[DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)，同时兼容独立 usage-only 事件。

## 5.2：取消边界与验证

同步 CLI 通过 InterruptibleTransport 驱动异步 HTTP IO；短周期等待让 Windows 的停止信号能被处理。取消只终止当前 IO，随后可复用客户端。存储仍在主调用线程，不把业务或文件锁搬进后台线程。

执行中的 Ctrl+C 结束当前轮次并回到输入；空闲输入的 Ctrl+C 退出。确认时 Ctrl+C 也取消，普通拒绝按工具拒绝处理。命令等待采用短周期轮询，取消后尽力清理进程树、回收直接子进程并记录 interrupted；已发生的副作用不回滚。流式取消保留中断前已收到的可靠用量。

`test_cancellation.py` 启动独立 CLI 进程与本地 HTTP 服务，在响应头等待、正文等待、已收到用量的正文等待、真实父子命令等待及确认处中断；辅助线程投递 Python SIGINT，未模拟模型调用函数或进程结果。验证返回输入框、可新建会话、旧轮次中断、未知消费阻止继续，以及实际父子进程均结束。该测试不替代物理键盘/终端的人工体验检查。

## 5.3：有限重试与物理请求记账

RequestPolicy 由一轮聊天共用：每次物理请求先占次数，仅 RequestNotSentError 可额外重试两次，退避 0.2/0.4 秒。自动摘要与聊天共用额度，摘要为正式回答预留一次；手动摘要独立受同样上限约束。每个摘要重试也产生独立操作记录。

HTTPX 的 ConnectError/ConnectTimeout 在响应建立前表示请求尚未发出，记 api_not_sent、零用量、失败；响应建立后即便出现同类异常也不重试。读取超时、读取错误、HTTP 401/429/500、协议错误、未知用量、取消和工具执行均不自动重试。日志保存失败停止，不以“未发出”掩盖不完整记录。

成功轮次可包含可靠零用量的连接失败尝试，但必须有成功请求；日志校验不允许把未知用量伪装成 api_not_sent。已完成工具不会因为后续连接重试而再次执行。测试见 `test_request_retry.py`，包括流式/非流式、摘要、共享预算、日志故障和真实命令仅执行一次。

## 5.4：失败后的继续方式

错误或取消后，CLI 查询应用的 ContinuationStatus，给出明确的下一步；不增加 /turn 或 /diagnose 命令。错误提示保留原始失败类别，继续方式说明只读取日志，不改变历史、消费或副作用。

| 当前证据 | 原会话能否再请求 | 处理 |
| --- | --- | --- |
| 失败/取消但用量可靠，工具结果明确，额度未耗尽 | 可以 | 调整输入后继续；旧失败输入不加入上下文 |
| 连接未建立且重试耗尽 | 可以 | 网络恢复后手动再次输入；此前零消费记录保留 |
| 请求已发出但用量未知 | 不可以 | 查看记录，/new 或 /resume 其他会话，不清零未知用量 |
| 命令或文件修改结果未知 | 不可以，摘要也禁止 | 先核对真实副作用，再新建会话，不重跑旧动作 |
| 会话消费已达上限 | 不可以 | 新建会话，或修改额度后重启恢复 |
| 日志读取失败 | 无法判定 | 检查权限/文件，不能根据缺失记录推断成功 |

`test_failure_recovery.py` 用真实 JSONL 重开失败会话，验证上述状态、失败输入隔离与 CLI 指引；`test_cancellation.py` 验证实际中断后的继续边界。可通过这些固定假模型场景重现失败链路；不是执行旧日志里的工具。详细定位沿用 `python -m adam.diagnostics <会话.jsonl>` 只读入口。

## 后续已确认规则

取消不回滚已发生的外部命令或文件修改；保留已完成记录，不自动重放副作用。未知用量保留当前会话以供查看和切换，但不能继续请求；已知用量且没有未知命令或编辑结果时可以继续。

仅连接建立失败可有限重试；读取超时、断流、未知用量、HTTP 拒绝和工具执行不自动重试。每次物理请求都受现有预算约束，保留独立请求/摘要记录。

交付范围是 Windows CLI 与 Python 环境，不制作 exe，不扩展 V2.3 真实模型评估平台。真实服务商能力和计费由手动清单验证，离线测试不冒充实际模型效果验收。
