按物理行号报告最早可观察错误，含时间、turn/request/tool关联、错误类型、日志哈希与该行之前的前缀哈希。识别请求/轮次失败或中断、工具明确错误以及非零退出码；同一工具的命令事件与工具回传不重复计算。失败后续事件列为secondary，第一候选列为primary。

“首次可观察失败”不是已证实根因。工具失败可能只是正常探测；日志候选归因置信度medium、root_cause始终not_proven。独立验证通过时不归因为任务失败；无失败但无独立验证时标证据不足。请求/工具全成功但独立终态错误时，明确报告final_verification_failed（终态错误证据high），不猜更早哪个决策出错。

本步不提供任意根因模型打分或自动修复。前缀哈希只是证据身份，不能代替环境快照；可重跑前缀留B32.2。
