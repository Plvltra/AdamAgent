| 接口 | 契约 |
| --- | --- |

| [QueryCursor](../adam/contracts/file_query.py) | 绑定规范化查询摘要、扫描版本和结果偏移；严格有界格式，来源或查询变化须从头查询 |

递归时跳过缓存、`.git`、symlink 和 junction，不泄露被拒绝路径；显式列举目录可包含 `.git` 目录项，但仍不越过权限。取消、扫描超限、对象消失都失败，不把部分清单冒充完整结果。调用方提供取消和期限检查；本 API 不自行创建线程或期限。

游标未签名、不是访问令牌，不授予任何路径权限，也不代表存有可恢复的服务端快照。B21.1.2 文本查询已加入实际读取字节的版本，不能仅凭 mtime 判断内容没有变化。目录扫描不是事务，后续仍需复核扫描期间变化并明确观察局限。

## B21.1.2 实际工具与模型续读

[FileQueries](../adam/tool_calls/file_queries.py) 负责扫描、版本复核和页面收集，FileTools 保留原入口与单文件读取。普通和并发调用沿用原工厂，每次调用独立状态，不依赖上次工具对象还活着。无需增加数据库、后台索引或新终端命令。

| 行为 | 具体约定 |
| --- | --- |
| 翻页 | 原参数外增加cursor和limit；把next_cursor原样带回，同一路径/查询/匹配方式才能继续；页大小允许调整 |
| 页面大小 | 文本最多50条，文件/直接目录最多200条；按最终JSON长度保留完整条目，不让原编码器变成丢失游标的preview |
| 单条过长 | 明确失败并提示提高max_result_chars或缩小范围；不跳过当前条目，匹配行最多展示500字符并标line_truncated |
| 来源变化 | 每页重新授权，比较规范查询和扫描版本；文本纳入实际字节SHA-256；扫描结束再查目录元数据，发现变化即失败 |
| 不完整范围 | skipped_entries是被排除目录项数量，skipped_files是匹配glob但无法搜索的文件数量；不能把这类无命中说成整个目录无匹配 |
| 限制 | 原条目数、单文件大小与协作期限保留；新增tool_limits.max_scan_bytes默认32MiB，上限100000000字节，每页重新计量 |
| 旧调用 | list_directory仍接受offset并返回next_offset，但旧offset无版本保护；不能与cursor混用 |

总读取预算成功时按实际字节扣减；无法取得完整读取数量的错误保守扣除本次可读上限，可能提前停止，但不会超预算后继续成功。检测文件增长预留一个字节；明确超大文件不打开，只记跳过。超时与取消贯穿目录、文件和行处理，是协作停止，不宣称能强制中断所有文件系统调用。

扫描清单包含授权范围的元数据，因此即使不匹配glob的文件发生变化，也可能让旧游标失效。这是偏保守的版本策略。两次目录观察和文件摘要不是跨文件原子快照；游标不授予权限。精确字面搜索仍为默认；B21.2已接入显式正则，见末节。

[14项新场景](../tests/features/test_file_query_pages.py) 验证三个工具各自61项续读不重不漏、512字符页面、单条过长、恢复mtime后的字节变化、撤权、跳过与总字节拒绝、扫描中变动和TOML。模拟HTTP驱动真实应用先取50条再取第51～61条，两次工具执行写入JSONL；更改源文件后禁止FileQueries、网络和进程，离线重放仍匹配。模型回复为预设，不代表真实模型自主选工具效果。

## B21.2.1 固定正则工作进程

B21.2.1先提供基础，B21.2.2已接入模型工具显式模式；默认仍为字面匹配。独立 [match_lines](../adam/tool_calls/regex_match.py) 接口将模式和文本交给 [固定脚本](../adam/tool_calls/regex_worker.py)，返回从1开始的匹配行号。模式是Python正则，逐行去掉行结束符后search，可用内联标志；不支持跨行表达式。

宿主使用当前解释器、`-I -S`、绝对脚本路径、固定工作目录和少量系统临时目录环境变量。脚本只依赖标准库，不从模型接收Python代码或文件路径。原环境中的API密钥不传入；临时文件传递有界请求与结果，避免管道写入阻塞妨碍取消。此接口不是通用代码执行工具，也不是操作系统沙箱。

模式最多1024字符，单次文本最多256KiB UTF-8，编码后请求另有上限。结果先形成每行一个字节的有界位图，完成后才返回；宿主复核前缀、长度和位值。期限默认1秒、可在接口中设置到30秒；每20毫秒等待检查取消。超时、取消或异常先杀死并回收可信直接子进程，不交付部分行号；固定脚本不创建后代。输入/输出和等待时长有界，尚未提供OS内存硬上限。

[17项新测试](../tests/features/test_regex_worker.py) 运行真实脚本，验证CRLF/CR行号、中文、锚点、空行、字面转义、非法表达式、启动前边界、`(a+)+$`实际超时，以及工作进程写出已接收标记后取消并回收；不以伪造开始事件代替真实请求。连同架构39项通过（2.67秒），Ruff、575个文件格式及Pyright通过。三份新文件全文和注释已审查，无旧源码删除；主线按 AGENTS.md 三级验证规则执行。B21.2.2 的配置、显式mode与文件来源接入见下节。


## B21.2.2 显式regex模式

`search_text` 新增 `mode`：省略或 `literal` 按字面文本搜索，只有 `regex` 进入固定工作进程；其他值失败。query在字面模式最多4096字符，正则最多1024字符，pattern仍是文件glob。正则按行匹配、不跨行，内联标志按Python正则语义解释。例如query为`^value=\d+$`、mode为regex，可找到数值赋值行；字面模式只找这些字符本身。

游标的查询摘要包含mode；不能将literal的游标接到regex，或者更换query后继续。来源摘要仍来自原目录观察与实际字节，所以同一来源、不同模式的generation可能相同，二者通过游标查询摘要区分。返回页保留原路径、行号、文件version和next_cursor。

配置新增 tool_limits.max_regex_file_bytes（默认及最高262144字节）和 regex_timeout_seconds（默认1秒、上限30秒）。每页先用空文本在固定进程校验语法，再对实际匹配文件分别启动工作进程；坏表达式在空目录也失败。每个进程只分配整次scan_timeout_seconds的剩余时间，不能靠多文件各自计时绕过总期限。文件太大、正则超时或语法错误是整次工具失败，不被普通不可读文件的跳过逻辑吞掉，也不自动退回其他模式或自动重试。

字面模式不启动进程。正则每文件启动解释器有开销，查询大目录时应缩小path/pattern；当前实现没有持久正则服务。固定进程输入输出有界且可回收，仍不提供OS内存硬上限。

[9项新业务测试](../tests/features/test_regex_search.py) 覆盖默认不创建进程、明确正则结果、模式混用/来源变化、空目录坏语法、尺寸与配置边界、真实灾难回溯超时及后续字面成功。模拟模型实际发起两次正则翻页，参数、结果和版本进入JSONL；修改源文件并禁止网络/子进程后离线重放匹配。首轮测试误将Message对象直接JSON编码，已改为验证原始保存的tool_calls.mode，未改生产边界。

相关122项通过（32.29秒），Ruff、576个文件格式及Pyright通过；新测试全文、实际源代码和注释差异已审查。原“默认字面”说明更新为“默认字面、显式正则”，有限读取、来源、取消、PDF与分页说明保留。B21.3的组合故障验收见下节；主线按 AGENTS.md 三级验证规则执行。


## B21.3 组合验收

[两项完整应用场景](../tests/features/test_search_acceptance.py) 使用模拟模型HTTP，文件查询、正则工作进程、JSONL和恢复均真实执行。

1. 第一页之后实际新增一个排序更靠前的文件。旧游标得到明确失败、不带部分匹配；模型再显式发起第一页查询，获得全部三项。三次执行、四次模型请求与已知48token保存；离线重放禁止扫描、网络和子进程仍匹配。
2. 语法检查进程结束后，等第二个匹配实际文本的进程写出已接收标记，再取消生产令牌。进程被回收、轮次中断、没有第二次模型请求，已知12token保留；有效聊天历史仍只有此前成功消息。

取消沿原工具调度语义传播：有tool_started、没有可交付结果就不制造tool_finished。首次持锁重启追加session_recovered，将缺失结束的工具标记interrupted/restart_recovery；轮次原中断记录和已知用量保留，不重跑查询。第二次重启不再追加事件。初次测试误期待取消也写tool_finished，已依据原协议改为核对上述真实证据，没有为测试制造成功结果。

相关121项通过（51.49秒），涵盖前述61项完整分页、模式/版本变化、实际复杂表达式超时、并发原工具循环、读取取消和架构；Ruff、577个文件格式及Pyright通过。新增测试与说明全文审查，生产架构无变更；主线按 AGENTS.md 三级验证规则执行。B21工程范围已完成，真实模型主动选择正则或续读的效果仍需个人验收。
