# B42 预算感知委派对照

入口：`python -m scripts.delegation_eval <新输出目录> --llm <模型配置路径> --live`。本轮只通过MockTransport验收，不调用付费API。输出每项result.json与总comparison.json。

固定任务：简单任务只读a.txt；独立任务分别读a.txt与b.txt。每个方案在相同但独立的目录中执行，宿主校验JSON结果及原文件未变。基线主Agent只有read_file；预算方案使用原spawn/wait和宿主预算策略。没有命令或编辑批准。

已验收：简单任务的委派尝试被策略拒绝，随后主Agent完成；独立任务启动1个子任务、回收真实结果并汇总。固定模拟中独立任务委派5次请求、60token，自己做2次请求。数字来自测试响应，只证明工程统计，不代表真实服务成本或质量优势。

失败样本：子模型返回正文但缺少usage，整组报告unknown_usage，总token为null；子任务最终failed，没有静默遗留运行，样本仍保留在总结果中。已有取消、进程中断和共享额度回收场景继续由V6及B39/B40验收覆盖。

当前选择：简单任务自己做；明确能独立拆分、已有结果已收集且预算足够时才考虑委派。估算不能代替实际请求准入，服务商计费也不是本地估算能保证的硬上限。真实模型成功率、耗时及质量收益待显式重复评估，不因子Agent数量增加就认定更好。
