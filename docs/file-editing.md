# 文件修改与验证

更新日期：2026-10-29。V4 按五个小任务实施，状态以 [练习 TODO](agent-practice-todo.md) 为准。

## 已确认的范围

- 专用编辑工具修改已有的单个文本文件，旧文本必须唯一匹配；多文件事务、创建、删除和重命名后置。
- 写入默认限于工作目录，额外范围由 permissions.additional_write_dirs 授权，与读取权限分开；禁止修改 .git，继续保护凭据路径。
- 只支持 UTF-8（含 BOM），保留 LF 或 CRLF；混合换行、孤立 CR、二进制、其他编码明确拒绝。
- read_file 返回完整文件的 SHA-256 版本；生成计划和获批写入前都核对。版本变化必须重新读取并提出修改。
- 每次展示实际路径和完整 diff，只有明确批准才写入。单文件采用临时文件替换；版本核对与替换之间仍有竞态窗口，不宣称跨程序事务。
- 模型用通用编辑和命令工具组织任务。每轮最多 3 次编辑执行尝试，同时服从既有请求、工具和 token 限额；这个数不是语义上的修复轮数。
- 编辑或命令被拒绝时，停止本轮剩余工具和请求，保留先前动作；下一条用户输入可以继续。
- 最终模型解释附程序生成的执行事实清单；命令正常退出不自动等于测试通过。
- 本轮进行假模型与真实文件、子进程、中断的工程验收。真实模型修复演示保留给用户练习，不调用付费 API。

## V4.1a：读取快照与修改计划（已实现）

read_file 的 version 对应与展示文本同一次读取的完整字节，分页和截断不改变版本含义。编辑使用完整原文规划，不使用带行号或截断的展示文本直接覆盖文件。

text_file.read_snapshot 有界读取并校验文本；edit_plan.plan_edit 对快照执行纯计算，返回路径、原版本、候选字节及 diff。旧文本为空、无匹配、多匹配（含重叠）、没有内容变化、版本失效或输出超限都会失败，原文件保持不变。diff 标明缺少末尾换行。

V4.1a 提供纯规划，V4.1c 已接入模型工具入口。

## V4.1b：确认与可靠写入（已实现）

EditTools.prepare 校验独立写权限并返回计划；replace_text 将这个计划交给确认回调，没有回调即拒绝。CLI 的 confirm_edit 展示实际路径和完整 diff，只接受 y/Y，取消或其他输入拒绝。

批准后先复查文件版本，写入同目录临时文件并 flush/fsync；替换前再次核对权限和版本，使用 os.replace 完成替换。可捕获的替换前失败保留原文件并尽力清理临时文件；不宣称断电持久性或跨进程事务，强杀可能遗留临时文件。权限变化也会使执行失败。

`permissions.additional_write_dirs` 与 additional_read_dirs 都相对 config.toml 所在目录解析，各自独立。额外写授权不自动提供模型读取权限，需要时分别配置；凭据和 .git 始终受保护，符号链接/junction 暂不支持写入。

## V4.1c：模型工具与编辑证据（已实现）

模型调用 `replace_text(path, old_text, new_text, expected_version)`。CLI 注入逐次 diff 确认，工具参数仍经过统一 Schema 校验。模型读取和修改之间版本不一致即拒绝生成计划；批准后冲突返回 conflict，模型需重新读取。

日志沿用 v4 扩展，旧 v4 仍可读取，旧程序不保证读取新编辑事件：
- edit_planned：父轮次、请求、工具与 edit_id，完整 diff、路径、原版本和目标版本；表示候选修改，尚未批准或写入。
- edit_started：批准已取得，开始记录成功后才进入文件写入；此后无结束事件就保持 unknown。
- edit_finished：applied / denied / conflict / failed、耗时和受控错误；applied 的 after_version 必须等于计划目标。
- 持锁恢复把只有计划的记录标为 not_started；未知写入结果继续 unknown。普通聊天及手动摘要均会拦截未知副作用，只读诊断仍可使用。
- 文件与会话日志不是同一事务。文件已改但结束日志失败时停止，不重发工具。记录成功但随后整轮失败时，编辑证据仍保留。

拒绝命令或编辑后，拒绝结果先落盘，然后终止本轮剩余工具及模型请求；这取代此前“拒绝命令后继续请求模型”的行为。此前动作保留，不自动回滚。下一条用户输入可以继续。

四个真实子进程强杀边界：计划后、开始后、替换后但结果未存、结果已存但轮次未提交。新进程恢复验证文件字节、状态、用量、备份和不重做；这些测试使用本地 HTTP，不消耗模型费用。

验收入口：[文件编辑业务测试](../tests/features/test_file_editing.py)。覆盖中文、引号、BOM、LF/CRLF、版本失效、无副作用失败及 diff。
