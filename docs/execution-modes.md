# 规划与执行模式（T4）

状态：T4.1～T4.3 已完成本地工程验收，包含模式策略、用户切换、请求记录、子任务继承与组合故障场景。
完整需求与进度见 [能力扩展任务](agent-maturity-tasks.md)。

## 用户目标与边界

plan 用于调查和形成方案，允许内部计划、反馈、会话记录及受限委派；不能执行文件修改或通用命令。
act 允许进入原有工具流程，路径规则、版本冲突、逐次批准及预算仍然生效。
模式由用户切换，不能从模型参数、工具文字、Skill 或 AGENTS.md 获得切换授权。
专用 Git 查询属于读取；run_command 即使参数看起来只读，也按进程执行能力限制。

## T4.1 实现

contracts/execution.py 定义 ExecutionMode、ToolCapability 和统一检查。
能力由可信注册代码声明，不发送为可由模型更改的工具参数：

| 能力 | 现有用途 | plan |
| --- | --- | --- |
| read_only | 文件/Git 查询、Skill 加载、文档检索、已配置且声明只读的 MCP | 允许，仍检查读取权限 |
| session_state | 计划和反馈记录 | 允许 |
| delegate | 受程序约束的委派和只读审查 | 允许，子任务继承派发时的模式 |
| edit_file | 专用文件编辑 | 阻止 |
| run_process | 通用命令 | 阻止 |
| unknown | 未声明的扩展工具 | 阻止，不根据名称或描述猜测 |

读取指不修改用户目标资料；文档检索自身的受限索引缓存仍可更新。
MCP 声明来自用户配置的可信服务，不构成对任意外部服务的操作系统隔离。
注册时声明错误属于扩展代码错误，不能把模式检查称为沙箱。

ToolRegistry 支持注入只读模式提供者。执行顺序为：参数校验 → 模式检查 → 路径规则预检 → 工具及原有审批。
目录扩展、规则包装保留能力和模式；扩展不能重标已有工具能力，重复绑定模式会失败。
模式阻止返回 ok=false、status=mode_blocked，跳过专用执行结果编码器；工具轨迹保留，编辑和命令没有实际执行记录。
该状态不触发自动反思，也不能作为计划完成的成功证据。

## T4.2 使用与运行边界

- `/mode` 查看当前模式；`/mode plan` 进入调查规划；`/mode act` 回到原有执行流程。
- 启动默认 act，并显示实际模式和限制。模式是当前应用的运行设置，/new、/resume 不改变它；退出后重新启动仍为 act。
- 命令不请求模型、不创建会话、不进入聊天历史。非法参数保留原模式。
- 一轮开始到子任务收尾结束期间不能切换，成功、失败或取消后解除占用；运行中重复提交同样拒绝。
- 模式说明与原系统提示合在同一条 system 消息中，整体计入受保护输入预算；/context 预览同一来源。程序仍在工具执行前检查，不依赖模型遵从提示。
- 聊天请求的 context.execution_mode 保存 plan/act；旧日志可没有该字段。会话原始系统提示和成功消息不写入临时模式说明。

ModeController 由 AgentApplication 持有；工具注册表、上下文和子任务管理器只获得模式读取函数。标准 bootstrap 同时连接这些边界。手动组装且未绑定控制器的旧应用保持原固定执行行为，切换请求明确报错，不能只改变终端显示。

每次子任务派发先将 execution_mode 保存到 ChildRun，再启动独立线程；子执行期间模式固定。追问同一个已结束的子 Agent 时捕获新主轮次的模式。plan 阻止子任务命令；act 也不增加原有子任务权限，需批准的操作仍交回主 Agent。旧索引缺少模式时按原 act 行为读取，非法模式报错；读取记录不自动重跑。

## T4.3 组合验收

- 使用实际 AGENTS.md、标准 Skill 或文件工具返回恶意切换指令；假模型仍提出切换/伪造参数/编辑/命令，程序保持 plan，零审批、零目标副作用。
- 启动真实 MCP stdio 子进程，plan 下读取与原生工具的内容/版本一致；随后编辑仍被拒绝。
- 用户切到 act 后拒绝一次审批，本轮停止，同批后续工具不执行；成功历史只保留已完成轮次。
- 自动摘要后实际聊天请求仍包含 plan，命令仍被拦截。
- 已关闭写入器的真实请求/子索引中，旧字段缺省可读，非法模式报错且不静默重写；新启动默认 act，全程不自动请求模型。
- 独立 CLI 进程在 plan 下通过真实 HTTP 收到部分正文后中断，用户可切回 act；未知用量仍阻止原会话继续，/new 后正常请求且不带失败输入。

以上验证程序边界，不以模拟模型证明真实模型遵从效果。已批准执行路径由 T4.2 场景覆盖；不重复复制完整场景。
